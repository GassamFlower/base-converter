# b-功能清单：Base Converter

> 依据 Vibe_Coding 立项门。由 `a-立项文档.md` 拆出，产出边界供阶段计划使用。

## 一、按角色拆解

| 角色 | 能做什么 |
|---|---|
| 访客（匿名，唯一角色） | 在首页任一转换器输入数字/字符串 → 实时看到转换结果 → 复制结果 |
| （无）管理员 / 商家 / 用户 | —— 本站无账号体系，无其他角色 |

> 本站是单角色"纯工具站"，无权限体系。所有功能都对"访客"开放。

---

## 二、按业务流程拆解（核心闭环）

**核心闭环：搜到 → 转换 → 复制**

```
打开转换器页面
  → 输入待转换值（b/d/h/o 其中一种，或 ascii）
  → 实时/点击算出目标进制结果
  → 点「复制结果」拿到可用值
  → 满足离开
```

**每个转换器都复用同一条流程**，只是输入进制和目标进制不同，因此"转换"可做通用组件一次实现。

## 三、按模块拆解（功能细节）

### F1 进制两两转换（核心模块）
- **给谁用**：访客
- **输入**：支持单个数字，进制为 BIN/DEC/HEX/OCT 之一
- **输出**：目标进制的字符串
- **权限**：无（开放）
- **正常流程**：选输入进制 → 输入数字 → 选目标进制 → 显示结果 → 复制
- **功能列表**：
  - BIN → DEC / HEX / OCT
  - DEC → BIN / HEX / OCT
  - HEX → BIN / DEC / OCT
  - OCT → BIN / DEC / HEX
- **支持**：负数（如 -10 → 二进制补码展示）、常用数值范围（64 位内，用 BigInt 处理整数）
- **异常边界**：
  - 输入包含非法字符（如 DEC 输入 "abc"）→ 提示/清空不报错
  - 输入超出安全整数范围 → 自动 BigInt 处理，仍可转
  - 空输入 → 无输出，不崩溃
  - HEX 常见 0x 前缀容忍（0xff 视为 ff）

### F2 复制结果
- **给谁用**：访客
- **输入**：转换结果字符串
- **输出**：复制到剪贴板（或提示"已复制"）
- **异常边界**：浏览器剪贴板权限受限 → 降级为提示用户手选复制（选中文本）

### F3 ASCII 转换块（带长尾）
- **给谁用**：访客
- **输入**：一段文本 或 HEX
- **输出**：文本 ⇄ HEX（UTF-8 编码），可给后续扩展字节
- **异常边界**：含不可打印字符 → 显示符或转义

### F4 首页 / 导航
- **给谁用**：访客 + SEO（搜索引擎机器人）
- **输出**：首页列出各转换器入口，带每个核心词的 TDK
- **SEO 落地**：每个转换器对应一个可爬取的页面/片段，命中 `binary to decimal` 等核心词

### F5 助记/说明区（长尾内容）
- **给谁用**：访客 + SEO
- **作用**：一小段"进制是什么 + 换算速查表"，撑搜索意图、供学生解惑，纯静态文本

## 四、复杂功能拆分说明

> 本站**没有**订单 / 支付 / 权限等复杂功能。
> 唯一可能变复杂的是"通用进制转换引擎（BigInt + 各底权值）"，它属于**架构设计文档**的公共逻辑，不单独拆文档，但会在功能清单里标注为"核心公共模块"。

- **核心公共模块**：`convert(input, fromRadix, toRadix, flags)` —— 集中处理一切进制换算，供所有转换器复用，避免每个接口各写一套。
