What is a base converter?

A base converter is a free tool that changes a number from one number system to another — binary (2), octal (8), decimal (10), or hexadecimal (16). Programmers and CS students use it every day to switch between how computers store numbers. This tool does it instantly, handles very large and negative numbers, and runs entirely in your browser.
